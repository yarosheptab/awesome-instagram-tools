# Contributing to Awesome Instagram Tools

Contributions are welcome! Please take a moment to review this document in order to make the contribution process easy and effective for everyone involved.

## Guidelines

- **Quality**: Only high-quality, well-maintained tools and resources should be added.
- **Description**: Keep descriptions short and descriptive. Start with a capital letter and end with a period.
- **Format**: Ensure your additions are properly formatted using Markdown. Use `[Title](Link) - Description.` format.
- **Alphabetical Order**: Try to keep items within sections in alphabetical order where it makes sense.
- **No duplicates**: Check if the resource is already in the list.
- **Check links**: Ensure the link is valid and does not redirect to a broken page.

## How to Contribute

1.  **Fork** the repository on GitHub.
2.  **Clone** the forked repository to your local machine.
3.  **Create a new branch** for your changes.
4.  **Make your changes** to `README.md`.
5.  **Commit** your changes with a clear and concise commit message.
6.  **Push** your changes to your fork on GitHub.
7.  **Submit a Pull Request** to the `main` branch of the original repository.

## Contribution Criteria

- The tool must be relevant to Instagram.
- It must be useful to a significant portion of the community.
- The project should be active or a stable reference.

Thank you for your contributions!
